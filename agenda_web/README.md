# Agenda Intelligent Web

Une version web moderne de l’agenda intelligent conçu pour lutter contre la procrastination.

## Fonctionnalités

- Ajouter des tâches pour un jour donné
- Cocher une tâche comme réalisée ou non
- Supprimer une tâche
- Clôturer la journée pour reporter automatiquement les tâches non accomplies au lendemain
- Interface moderne et agréable

## Lancer l’application

```bash
pip install -r requirements.txt
python app.py
```

Puis ouvrir l’URL : http://127.0.0.1:5000

## Fichiers principaux

- `app.py` : backend Flask
- `templates/index.html` : interface principale
- `static/styles.css` : style moderne
- `static/script.js` : logique front-end
